## Fuentes oficiales a usar

- [scipy.stats — main namespace](https://docs.scipy.org/doc/scipy/reference/main_namespace.html) — funciones, parámetros, distribuciones, tests, resampling.
- [statsmodels — user guide](https://www.statsmodels.org/stable/user-guide.html) — modelos, supuestos, estructura de la librería.
- [statsmodels — API reference](https://www.statsmodels.org/stable/api.html) — clases, métodos, argumentos, retornos.
- [statsmodels — examples](https://www.statsmodels.org/stable/examples/index.html) — patrones correctos de implementación.

## Cómo combinar fuentes para SciPy

1. **Practical Statistics for Data Scientists** → explicación conceptual.
2. **Think Stats** → intuición / simulación.
3. **SciPy docs** → implementación correcta y actual.
